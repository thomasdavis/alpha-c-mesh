# @ajax/pathtrace-default-scene

programs/pathtrace's default scene as scene-format words (`@ajax/pathtrace-scene`): 640×360, 8 samples
per pixel per pass, 32 passes, depth 8; 9 materials, 6 quads, 4 spheres and a 20-triangle mesh. The
words were generated by the Rust repo's `programs/pathtrace/scene.py` and are copied unchanged.

**Ported from** `crates/pathtrace-core/src/scene_data.rs` (`DEFAULT_SCENE`). Freestanding data.

**Tested** by every renderer golden test (`@ajax/pathtrace-f32`, `-z`, `@ajax/mesh-ref-pathtrace`), and
validated in `@ajax/pathtrace-job-scene`'s tests.
