# @ajax/mesh-check

Test checks for alpha-c-mesh's packages: CHECK, CHECK_U, CHECK_I, CHECK_S, then mesh_check_done().

```c
#include "mesh/check.h"
```

## Ported from

[alpha-rust-mesh](https://github.com/rsafier/alpha-rust-mesh) (Richard Safier, MIT): nothing: the test checks this repo uses.

## Device code

Host only (it prints with stdio).

## Tests

- none of its own: it is exercised by the packages that use it
