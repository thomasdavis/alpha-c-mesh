# @ajax/tui-golden

Not published: the tui widgets checked cell for cell against ratatui 0.30.2 on 1900 random configurations.

Part of the C port of [alpha-rust-mesh](https://github.com/rsafier/alpha-rust-mesh)'s `mesh-top`, a
terminal UI built with ratatui: these packages reproduce what ratatui and its Unicode crates compute,
so a frame drawn in C is the same, cell for cell, as the Rust one.

## Ported from

[alpha-rust-mesh](https://github.com/rsafier/alpha-rust-mesh) (Richard Safier, MIT)'s `mesh-top` uses it through ratatui; the C follows Not published. The tui widgets against ratatui 0.30.2: 1900 random configurations of Paragraph (wrap, trim, scroll, alignment), Table (widths, flex, spacing, selection, highlight), Sparkline and Chart, generated by a scratch Rust program (see docs/port/top.md).

## Tests

`tests/widgets.c` replays every case from `tests/data/widgets.txt` and compares every cell.
